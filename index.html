🎚️ 최근에 더 무게를: 지수 평활

새 평활값 = α × 오늘 값 + (1 − α) × 어제 평활값. 10일째에 매출이 갑자기 한 단계 오른 가상 데이터입니다.

α (알파)0.5

ADF p 값은 원고의 statsmodels adfuller 기본값 결과(누적 0.897, 차분 2.0 × 10⁻²⁹)입니다. "다시 던지기"로 만든 새 그래프에는 이 앱이 계산한 간이 DF 통계량을 보여 줍니다(랜덤 워크라도 약 5%는 우연히 '정상'으로 판정될 수 있습니다).

📐 정상성: 판 자체가 그대로인가

평균과 분산이 시간이 흘러도 변하지 않아야 과거에서 배운 규칙이 미래에도 통합니다. 손질 방법을 골라 보세요.

🚨 잔차로 찾는 이상 징후

seasonal_decompose(period=7, additive) 결과. 점을 눌러 날짜와 잔차를 확인하세요.

경계 ×σ3

🐼 판다스로 한 번에

import numpy as np, pandas as pd from statsmodels.tsa.seasonal import seasonal_decompose from statsmodels.tsa.stattools import adfuller s.rolling(3).mean() # 이동 평균 s.ewm(alpha=0.3, adjust=False).mean() # 지수 평활 s.diff() # 차분 (계절 차분: s.diff(12)) d = seasonal_decompose(s, period=7, model="additive") d.trend, d.seasonal, d.resid # 추세 · 계절 · 잔차 adfuller(s)[1] # ADF 검정 p 값 walk = np.random.default_rng(28).choice([-1, 1], 200).cumsum() # 동전 그래프

📌 세 줄 정리

  1. 시계열은 추세·계절·순환·잔차로 나뉘고, 폭이 커지면 곱셈 모형이나 로그를 쓴다.
  2. 이동 평균은 창 안을 고르게, 지수 평활은 최근에 무게를 두어 잡음을 걷는다.
  3. 예측 전에 정상성을 확인하고 차분하며, 튀는 잔차로 이상 징후를 찾는다.
