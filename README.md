# 동전 차트 감별소

오르는 그래프의 정체는 동전 던지기? — 시계열을 읽는 법을 손으로 체험하는 앱입니다. 200일 동안 0에서 30까지 오른 "차트"가 사실은 동전 던지기 누적 합이라는 사건(원고와 같은 시드 28), 동전 12번 실험, 추세·계절·잔차를 조립해 보는 덧셈·곱셈 모형, 창 길이를 바꾸는 이동 평균, α로 무게를 정하는 지수 평활, 랜덤 워크와 하루 차이(차분), ADF·간이 DF 검정, 로그와 차분·계절 차분, 요일 주기를 드러내는 자기상관, 분해 잔차와 3σ 경계로 찾는 이상 징후까지 담았습니다. 빅데이터 09 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 성분: 동전 차트 사건과 다시 던지기, 12번 실험, 성분 조립(덧셈·곱셈 모형)
- ② 평활: 이동 평균 창 길이, 퀴즈 ①(24), 지수 평활 α와 무게, 퀴즈 ②(106)
- ③ 정상성: 랜덤 워크 vs 하루 차이와 검정, 로그·차분·계절 차분
- ④ 이상 징후: 자기상관, 분해 네 칸과 잔차 경계, 판다스·statsmodels 코드, 세 줄 정리, 생각해 볼 질문
